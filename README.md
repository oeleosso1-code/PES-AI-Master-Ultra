# PES AI Master Ultra (Android)

Native Kotlin Android demo. Includes one-button start/stop, fast local simulated football tactical decisions, and dynamic formations. Does **not** read or control PES/eFootball and does not guarantee compatibility with third-party games. Decisions are based on random simulation inputs.

## Build an installable APK using GitHub
1. Create your own GitHub repository, upload all files preserving directories.
2. Open **Actions** > **Build Android APK** > **Run workflow** (or push to main).
3. Download artifact **PES-AI-Master-Ultra-debug-APK**, unzip, and install `app-debug.apk` on Android.

Android Studio: open the project and run Gradle task `:app:assembleDebug`.

Only install software from repos you trust. Debug APK isn't signed for production distribution.
